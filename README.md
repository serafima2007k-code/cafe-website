# Веб-интерфейс для кафе

## Описание проекта

Веб-сайт для кафе с домашней выпечкой. Реализована клиентская часть (frontend) без серверной логики. Сайт позволяет пользователям просматривать меню, фильтровать блюда по категориям, добавлять понравившиеся позиции в избранное (с сохранением в localStorage) и отправлять форму бронирования столика с клиентской валидацией.

## Функциональные возможности

- Просмотр меню с карточками блюд
- Фильтрация блюд по категориям («Всё», «Кофе», «Десерты», «Закуски»)
- Добавление и удаление блюд в избранное
- Сохранение избранного в localStorage
- Валидация формы бронирования столика (проверка имени, email, даты)
- Адаптивная вёрстка (ПК, планшет, телефон)

## Технологии

- HTML5 (семантическая вёрстка)
- CSS3 (Flexbox, Grid, медиа-запросы)
- JavaScript (классы, модули, localStorage)

## Как пользоваться сайтом

**1. Главная страница** – при открытии сайта вы попадаете на главную страницу, где размещено приветствие с описанием концепции кафе и кнопка «Посмотреть меню». Нажмите на неё, чтобы перейти к просмотру блюд. В верхней части страницы находится навигационное меню, с помощью которого можно быстро переключаться между разделами: «Главная», «Меню», «Избранное», «Контакты».

**2. Просмотр меню** – в разделе «Меню» все блюда представлены в виде карточек. Каждая карточка содержит изображение блюда, его название, краткое описание, цену и кнопку-сердечко для добавления в избранное. Чтобы добавить понравившееся блюдо в избранное, нажмите на сердечко – оно станет активным (заполненным).

**3. Фильтрация меню** – над списком блюд расположены кнопки фильтров: «Всё», «Кофе», «Десерты», «Закуски». Нажмите на кнопку «Кофе», чтобы увидеть только кофейные напитки. Нажмите на кнопку «Десерты» – увидите только десерты. Кнопка «Всё» показывает все позиции меню снова. Если в выбранной категории нет блюд, появится сообщение «Ничего не найдено».

**4. Работа с избранным** – все блюда, которые вы отметили сердечком, сохраняются в разделе «Избранное». Чтобы удалить блюдо из избранного, нажмите на активное сердечко ещё раз – оно станет неактивным, и блюдо исчезнет из раздела «Избранное». Счётчик избранного (цифра рядом с иконкой сердечка в шапке сайта) показывает количество добавленных позиций.

**5. Бронирование столика** – в разделе «Контакты» вы найдёте адрес кафе, телефон и часы работы. Для бронирования столика заполните форму обратной связи: укажите ваше имя, электронную почту и желаемую дату визита. После заполнения всех полей нажмите кнопку «Забронировать». Если все поля заполнены корректно, появится сообщение «Успешно отправлено», а форма очистится. Если вы забыли заполнить какое-то поле или ввели email без символа «@», появится сообщение с пояснением ошибки.

## Запуск проекта

1. Скачайте все файлы проекта
2. Откройте файл `index.html` в любом современном браузере
3. Или используйте Live Server в VS Code для удобной разработки
